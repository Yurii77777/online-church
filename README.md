# Онлайн Церква

Православна онлайн-церква для розробників. Поставити свічку за успішний деплой, освятити MacBook святою водою, сповідатись перед AI-пастором, замовити панахиду по legacy-коду — все це тепер можливо онлайн.

## Сторінки

| Маршрут | Опис |
|---------|------|
| `/` | Головна — привітання від диякона, навігація та QR-код для пожертв |
| `/candle` | Вибір молитовного наміру (18 dev-тематичних інтенцій) |
| `/candle/burn` | 3D анімація горіння свічки (Three.js + GLSL шейдери) |
| `/bless` | Вибір предмета для освячення (MacBook, код, резюме, м'ясо...) |
| `/bless/holy` | Анімація окроплення святою водою (Canvas 2D) |
| `/confession` | Сповідальня — AI-пастор приймає сповідь і відпускає IT-гріхи |
| `/requiem` | Панахида — AI відспівує legacy-код, провалені релізи, deprecated API |
| `/prayer` | Молебень — персональна AI-молитва перед співбесідою чи важливою подією |
| `/project` | Освячення проекту — духовний аудит та благословення проекту перед початком (для PM-ів) |
| `/indulgence` | Індульгенція — AI відпускає IT-гріхи наперед, canvas-сертифікат з PDF завантаженням |
| `/saints` | Книга Святих — сторінка контриб'юторів/донатерів |

## Технології

- **SvelteKit 2** + **Svelte 5** (runes) — фреймворк
- **Vercel AI SDK** + **OpenAI GPT-4o** — AI-пастор (сповідь, панахида, молебень)
- **Threlte / Three.js** — 3D свічка з процедурним полум'ям (GLSL шейдери)
- **Canvas 2D** — частинкові системи (краплі води, дим кадила), сертифікат індульгенції
- **jsPDF** — клієнтська генерація PDF (динамічний імпорт)
- **Howler.js** — аудіо (тріск свічки, плюскіт води)
- **Tailwind CSS 4** — стилізація
- **TypeScript** — типізація
- **adapter-auto** — деплой на Vercel

## Ефекти

- 3D свічка з анімованим полум'ям, воском що тане та крапає
- Окроплення святою водою з фізикою крапель, бризками та стіканням по склу
- Пергаментний сертифікат індульгенції (Canvas 2D: градієнти, шум, золота рамка, сургучна печатка)
- Фоновий дим кадила (Canvas 2D particle system) на всіх сторінках
- Фонова музика Kiasmos (loop, 30% volume, lazy load)
- Звукові ефекти: тріск свічки, плюскіт води

## Змінні середовища

| Змінна | Опис |
|--------|------|
| `OPENAI_API_KEY` | API ключ OpenAI (обов'язково) |
| `OPENAI_MODEL` | Модель OpenAI (за замовчуванням `gpt-4o`) |
| `BASE_PATH` | Base path для деплою (наприклад `/online-church` для GitHub Pages) |

## Розробка

```sh
npm install
npm run dev
```

Для роботи AI-функцій локально створіть `.env`:

```
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-4o
```

## Деплой

Проект задеплоєний на **Vercel**. `adapter-auto` автоматично визначає середовище.

```sh
npm run build
```
