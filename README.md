# Онлайн Церква

Православна онлайн-церква для розробників. Поставити свічку за успішний деплой, освятити MacBook святою водою, потрапити до Книги Святих — все це тепер можливо онлайн.

## Сторінки

| Маршрут | Опис |
|---------|------|
| `/` | Головна — привітання від диякона, навігація та QR-код для пожертв |
| `/candle` | Вибір молитовного наміру (13 dev-тематичних інтенцій) |
| `/candle/burn` | 3D анімація горіння свічки (Three.js + GLSL шейдери) |
| `/bless` | Вибір предмета для освячення (MacBook, код, SSH-ключі...) |
| `/bless/holy` | Анімація окроплення святою водою (Canvas 2D) |
| `/saints` | Книга Святих — сторінка контриб'юторів/донатерів |

## Технології

- **SvelteKit 2** + **Svelte 5** (runes) — фреймворк
- **Threlte / Three.js** — 3D свічка з процедурним полум'ям (GLSL шейдери)
- **Canvas 2D** — частинкові системи (краплі води, дим кадила)
- **Howler.js** — аудіо (тріск свічки, плюскіт води, фоновий амбієнт)
- **Tailwind CSS 4** — стилізація
- **TypeScript** — типізація
- **adapter-static** — статичний експорт для GitHub Pages

## Ефекти

- 3D свічка з анімованим полум'ям, воском що тане та крапає
- Окроплення святою водою з фізикою крапель, бризками та стіканням по склу
- Фоновий дим кадила (Canvas 2D particle system) на всіх сторінках
- Фонова церковна музика (loop, 30% volume)
- Звукові ефекти: тріск свічки, плюскіт води

## Розробка

```sh
npm install
npm run dev
```

## Збірка

```sh
npm run build
npm run preview
```

Деплой на GitHub Pages через `adapter-static` з base path `/online-church`.
